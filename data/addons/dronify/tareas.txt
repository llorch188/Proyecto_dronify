# Resumen del Proyecto Dronify

## 1. Introducción
Dronify es un módulo Odoo para la gestión de drones, pilotos, clientes, paquetes y vuelos. El proyecto extiende el modelo `res.partner` para gestionar tanto pilotos como clientes.

## 2. Requisitos principales
- `res.partner` extendido con: `es_cliente`, `es_vip`, `es_piloto`, `licencia`, `dron_autorizado_ids`
- Modelos: `dronify.drones`, `dronify.paquetes`, `dronify.vuelos`
- Validaciones de licencia y roles
- Vistas separadas para Pilotos y Clientes
- Cálculos de `peso_total` y `consumo_estimado`
- Botones y flujo de estados para vuelos
- Uso de `logica_dronify.py`
- Diagrama E-R
- README con diario
- nombre/icono correcto en `__manifest__.py`

## 6. Notas
- El menú Pilotos debe incluir `context`: `{'default_es_piloto': True}`
- El menú Clientes debe incluir `context`: `{'default_es_cliente': True}`
- `es_vip` visible solo si `es_cliente=True`
- `licencia` visible solo si `es_piloto=True`
